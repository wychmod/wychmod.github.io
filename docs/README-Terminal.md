# 命令行终端使用指南

> 开发工具 / 终端 · TERMINAL MANUAL
> 本页仅解释站点已有的命令行系统，不创建新终端。命令、快捷键与本地存储均以当前仓库 `docs/index.html` 的终端实现为准。

这个终端不是为了模拟一台真实服务器，而是为知识库保留一条更快的键盘路径。当你已经知道自己要找什么，命令比鼠标逐层展开侧边栏更直接；当你还不确定关键词，`find`、`tree`、`recent` 和 AI 命令可以把阅读路径重新拉出来。

终端复用站点已有的 `#terminal-window`，不引入第二套命令行，也不占用其他面板的快捷键。下面列出的是当前真实可用的打开方式、快捷键、命令、错误恢复与本地存储说明。

---

## 何时使用终端

- 已经知道文档名或关键词，想跳过侧边栏逐层展开。
- 想搜索某个技术栈（如 Redis、Spring、Kubernetes）相关的文档。
- 想查看自己最近访问过哪些文章。
- 想让 AI 助手根据问题推荐文档或给出技术指导。

## 打开与关闭

| 行为 | 方式 |
|---|---|
| 打开 | 点击页面右下角悬浮按钮 `►_` |
| 打开 | 点击顶部导航栏的终端按钮（标注 `Ctrl K`） |
| 打开 / 关闭 | `Ctrl + K`（Windows/Linux）或 `Cmd + K`（macOS） |
| 关闭 | `Esc`（终端激活时） |
| 关闭 | 点击终端窗口外的遮罩层 |
| 关闭 | 点击终端窗口左上角的关闭按钮 |
| 关闭 | 输入 `exit` 或 `quit`，输出告别信息后自动关闭 |

> 终端首次打开时会显示欢迎信息，提示输入 `help` 查看命令、`readme` 查看知识库简介。

---

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + K` / `Cmd + K` | 打开或关闭终端 |
| `Esc` | 关闭终端（激活时） |
| `Enter` | 执行当前输入 |
| `↑` / `↓` | 浏览上一条 / 下一条历史命令 |
| `Tab` | 自动补全命令名；存在多个匹配时列出候选 |
| `Ctrl + L` | 清空终端输出 |

> 当前终端未实现 `Ctrl + C` 中断。如需中断当前输入或清屏，可使用 `Ctrl + L` 清空输出，或 `Esc` 关闭终端后重新打开。

## 命令总览

以下按用途分组列出当前 `Commands` 对象中的全部真实命令与别名，可作为快速索引。

### 文件系统与文档导航

| 命令 | 说明 | 示例 |
|---|---|---|
| `pwd` | 显示当前所在路径 | `pwd` |
| `ls [路径]` | 列出当前或指定目录的内容，并统计目录与文件数 | `ls`、`ls 计算机基础` |
| `cd [目录]` | 切换目录；无参数回到根目录；支持 `..` 与 `/` | `cd 计算机基础`、`cd ..`、`cd /` |
| `cat <文件>` | 打开指定文档；支持带或不带 `.md` 后缀；以 `/` 开头时按路由路径直接跳转 | `cat /md/02-后端开发/10-Redis缓存.md` |
| `tree [路径]` | 显示目录树（深度限制为 3 层） | `tree`、`tree 云原生与运维` |

### 搜索与阅读记录

| 命令 | 说明 | 示例 |
|---|---|---|
| `find <关键词>` | 在文档树中模糊搜索标题或路径，不区分大小写 | `find Redis` |
| `grep <关键词> <任意第二参数>` | 搜索别名：将第一个参数作为关键词调用 `find`（当前实现要求至少两个参数） | `grep Redis ls` |
| `readme` | 查看知识库简介与快速开始提示 | `readme` |
| `recent` | 显示最近 5 条访问记录 | `recent` |
| `stats` | 显示文档总数、分类数与技术栈分布 | `stats` |

### 系统辅助命令

| 命令 | 说明 | 示例 |
|---|---|---|
| `help` | 显示可用命令列表 | `help` |
| `man <命令>` | 显示命令手册（目前为 `ls`/`cd`/`cat`/`find` 提供详细手册，其他命令返回"无手册条目"） | `man ls` |
| `history` | 显示当前会话的命令历史 | `history` |
| `clear` | 清空终端输出 | `clear` |
| `whoami` | 显示作者信息 | `whoami` |
| `about` | 显示知识库统计与简介 | `about` |
| `fortune` | 随机输出一条技术名言 | `fortune` |
| `neofetch` | 显示系统信息面板 | `neofetch` |
| `echo <文本>` | 回显文本 | `echo hello` |
| `exit` | 输出告别信息并关闭终端 | `exit` |

### 命令别名

| 别名 | 等价于 |
|---|---|
| `quit` | `exit` |
| `open <文件>` | `cat <文件>` |
| `view <文件>` | `cat <文件>` |
| `ll [路径]` | `ls [路径]` |
| `dir [路径]` | `ls [路径]` |
| `ask <问题>` | `ai <问题>` |

### AI 助手命令

| 命令 | 说明 | 示例 |
|---|---|---|
| `ai <问题>` | 调用 AI 助手回答技术问题并推荐文档（远程 LLM） | `ai 如何优化 MySQL 查询？` |
| `aiconfig [key] [value]` | 查看或设置 AI 配置；不带参数时显示当前状态 | `aiconfig`、`aiconfig apikey YOUR_KEY` |
| `aisearch <关键词>` | 本地智能文档搜索（不调用远程 LLM，返回最多 5 条结果） | `aisearch Spring` |

## 使用示例

### 查找并打开文档

```bash
$ find Redis
$ cat /md/02-后端开发/10-Redis缓存.md
```

### 浏览分类目录

```bash
$ ls
$ cd 计算机基础
$ ls
$ cat /md/01-计算机基础/00-Java与JVM.md
```

### 查看最近访问与统计

```bash
$ recent
$ stats
$ tree 云原生与运维
```

### 配置并使用 AI 助手

```bash
$ aiconfig
$ aiconfig apikey YOUR_KEY
$ aiconfig apiurl YOUR_URL
$ ai 如何复习 JVM 内存模型？
```

## AI 助手配置

`ai` 与 `ask` 通过 `ai-assistant.js` 调用远程 LLM 接口，需要预先配置 API Key 与 API URL。`aisearch` 是本地文档搜索，不需要任何配置即可使用。

`aiconfig` 支持的配置键如下：

| 配置键 | 等价写法 | 作用 | localStorage 键 |
|---|---|---|---|
| `apikey` | `api_key` | 设置 API Key | `AI_API_KEY` |
| `apiurl` | `api_url` | 设置 API URL（需指向聊天补全端点） | `AI_API_URL` |
| `model` | — | 设置模型名称 | `AI_MODEL` |

查看当前配置：`aiconfig`。设置单项：`aiconfig apikey YOUR_KEY`、`aiconfig apiurl YOUR_URL`、`aiconfig model YOUR_MODEL`。

> 安全提醒：不要把真实 API Key 写进 Markdown、截图、Issue 或提交记录。浏览器 `localStorage` 只适合个人设备上的本地配置，不应在公共设备或共享浏览器上长期保存敏感 Key。文档中所有 Key 仅以 `YOUR_KEY`、`YOUR_URL`、`YOUR_MODEL` 等占位符出现。

## 错误与恢复

| 现象 | 可能原因 | 恢复方式 |
|---|---|---|
| `Command not found: '...'` | 命令不存在或拼写错误 | 输入 `help` 查看可用命令列表 |
| `No such directory: '...'` | 目录名拼写错误或不在当前路径下 | 先 `pwd` 查看当前位置，再 `ls` 列出可用目录 |
| `File not found: '...'` | 文件名不匹配 | 用 `find <关键词>` 搜索，或改用 `/md/...` 路径 |
| `'...' is a directory` | 对目录使用了 `cat` | 先 `cd` 进入目录，或 `ls` 查看其内容 |
| `Not a directory: '...'` | 对文件使用了 `cd` | 改用 `cat` 打开文件 |
| `Missing argument. Usage: ...` | 命令缺少必要参数 | 按提示补全参数，如 `find Redis` |
| `No results found for: '...'` | 搜索关键词无匹配 | 更换关键词，或改用 `aisearch <关键词>` 做本地智能搜索 |
| `AI助手模块未加载` | `ai-assistant.js` 未成功加载 | 刷新页面；若仍失败，检查网络与脚本加载状态 |
| AI 提示配置缺失或 API 错误 | 未配置 API Key / URL，或配置有误 | 输入 `aiconfig` 查看状态，再用 `aiconfig apikey YOUR_KEY` 等命令补全 |

## 隐私与本地存储

终端的所有状态都保存在浏览器 `localStorage` 中，不会上传服务器，也不会随仓库提交：

| 数据 | localStorage 键 | 容量 | 说明 |
|---|---|---|---|
| 命令历史 | `terminalHistory` | 最近 100 条 | `history` 命令查看；`↑`/`↓` 浏览 |
| 阅读记录 | `readingHistory` | 最近 20 条 | `recent` 显示其中最近 5 条 |
| AI 配置 | `AI_API_KEY` / `AI_API_URL` / `AI_MODEL` | 各 1 项 | 由 `aiconfig` 维护 |

> 切换浏览器、清理站点数据或使用隐私模式后，上述历史与配置都会丢失。不要在公共设备或共享浏览器上长期保存真实 API Key。

## 路径规则与注意事项

- 绝对路径以 `/` 开头，如 `/md/02-后端开发/10-Redis缓存.md`。
- 相对路径从当前目录开始，如 `Redis缓存`；`..` 返回上一级，`.` 表示当前目录，无参数的 `cd` 回到根目录。
- 目录与文件名匹配不区分大小写。
- `cat` 支持 `文件名.md` 或不带后缀的 `文件名`；以 `/` 开头的参数会作为路由路径直接跳转。
- `tree` 输出深度限制为 3 层，过深的归档目录不会完整展开。
- `man` 目前仅为 `ls`、`cd`、`cat`、`find` 提供详细手册，其他命令会返回"无手册条目"。
- 终端输出中带有 emoji（如目录与文件前的图标）属于现有实现的历史事实，本手册不再扩散使用。
- 终端基于 Docsify 4.x 与原生 JavaScript 实现，无外部依赖；移动端访问时会自动适配屏幕尺寸。

## 命令更新与维护规则

当 `docs/index.html` 中的 `Commands` 对象、快捷键处理或 `ai-assistant.js` 的配置键发生变化时，本指南必须以源码为准重新核对：新增命令需补入对应分组，移除的命令需从手册中删除，不得保留源码中已不存在的命令（如本版已移除的 `search`）。文档与终端实现之间不得出现事实漂移。
