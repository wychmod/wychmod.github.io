方法注记

encodeURI 适合处理完整 URL，会保留 : / ? # & = 等结构字符。

encodeURIComponent 适合处理查询参数值，会把结构字符一并编码。

URL 结构解析基于浏览器 URL API，只检查语法结构，不请求目标地址。
