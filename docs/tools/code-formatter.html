格式规范

          
当前格式化器是手写规则，不是 AST：

          
JSON 走 JSON.parse 严格解析；HTML 按标签分行缩进；CSS 按规则块换行；SQL 在关键词前换行并大写；C 风格语言（JS / Java / C++ / C# / Go / Rust / PHP）基于 { }、;、, 粗略缩进；Python 基于冒号与行粗略缩进。

          
Tab 在输入框插入两个空格；不同语言格式化器中缩进空格数不统一，并非可配置参数。

        

        

          
为什么格式化前的代码难读

          
    
            
  • 缩进缺失或混乱，结构层级不可见
    • 
            
  • 多条语句粘连在一行，难以定位边界
    • 
            
  • 大括号、分号、逗号无规则换行
    • 
            
  • 复杂表达式与嵌套挤成一团
    • 
            
  • 压缩代码去掉所有空白，人眼不可读
    • 
          

        

        

          
隐私与快捷操作

          
所有代码处理在浏览器本地完成，不上传、不保存、不执行。

          
本工具不会运行你粘贴的代码，输出区只渲染转义后的文本与语法高亮 span，<script> 等内容会被转义为纯文本，不会执行。

          
快捷键：Ctrl + Shift + F 格式化、Ctrl + Shift + C 复制结果、Tab 插入两个空格。不占用 Ctrl / Cmd + K。
