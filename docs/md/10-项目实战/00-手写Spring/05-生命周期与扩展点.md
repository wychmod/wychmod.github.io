# 手写 Spring：生命周期与扩展点

> **原文归档**：[old-spring-notes](/md/archive/README?id=old-spring-notes)
> **参考实现**：[wychmod/mini-spring](https://github.com/wychmod/mini-spring)
> **本章目标**：把 bean 从“实例化”到“初始化”再到“销毁”的整条生命周期讲清楚。

---

## 一、bean 不是 new 完就结束

Spring 最重要的地方之一，是 bean 有完整生命周期。
一个 bean 不是只经历“创建”，而是会经过多个回调点。

| 阶段 | 做什么 |
|---|---|
| 实例化 | 先把对象 new 出来 |
| 属性填充 | 把依赖和普通值写进去 |
| Aware 回调 | 让 bean 感知容器信息 |
| 初始化 | 执行 `afterPropertiesSet` / `init-method` |
| 销毁 | 执行 `destroy` / `destroy-method` |

## 二、Aware 是什么

`Aware` 家族的作用，是让 bean 感知容器内部的信息。

| 接口 | 感知什么 |
|---|---|
| `BeanNameAware` | 当前 bean 名称 |
| `BeanFactoryAware` | 当前 BeanFactory |
| `BeanClassLoaderAware` | 当前 ClassLoader |
| `ApplicationContextAware` | 当前 ApplicationContext |

你的实现里，这些回调在 `initializeBean()` 前半段被调用，属于初始化前的一部分。

## 三、初始化回调有两套

Spring 同时支持接口式和配置式两套初始化方式：

| 方式 | 写法 | 触发点 |
|---|---|---|
| 接口式 | `InitializingBean.afterPropertiesSet()` | 属性填充后 |
| 配置式 | `init-method="init"` | 属性填充后 |

你的当前实现做了一个简化：如果 bean 实现了 `InitializingBean`，`invokeInitMethods()` 就不会再调用配置式 `init-method`。真实 Spring 在方法不重复时可以让两者都执行；复刻时如果想更贴近 Spring，需要把这两个分支拆开判断。

销毁也类似：

| 方式 | 写法 | 触发点 |
|---|---|---|
| 接口式 | `DisposableBean.destroy()` | 容器关闭时 |
| 配置式 | `destroy-method="close"` | 容器关闭时 |

## 四、initializeBean 的顺序

`AbstractAutowireCapableBeanFactory.initializeBean()` 的顺序很清楚：

1. 处理 `Aware` 回调。
2. 执行 `BeanPostProcessor` 的前置处理。
3. 执行初始化方法。
4. 执行 `BeanPostProcessor` 的后置处理。

```java
if (bean instanceof BeanNameAware) {
    ((BeanNameAware) bean).setBeanName(beanName);
}
Object wrappedBean = applyBeanPostProcessorsBeforeInitialization(bean, beanName);
invokeInitMethods(beanName, wrappedBean, beanDefinition);
wrappedBean = applyBeanPostProcessorsAfterInitialization(wrappedBean, beanName);
```

这说明初始化不是一个点，而是一条流水线。

## 五、销毁也要登记

`registerDisposableBeanIfNecessary()` 会在 bean 创建完成后判断：

1. 它是不是单例。
2. 它是不是实现了 `DisposableBean`。
3. 它有没有配置 `destroy-method`。

如果有，就包一层 `DisposableBeanAdapter`，最后在 `destroySingletons()` 时统一销毁。

> 💡 补充：销毁只针对单例更合理，因为 prototype 一般由调用方自己负责生命周期。

## 六、从 0 复刻时怎么写

最小版本只要这几步：

1. 先定义 `Aware` 家族接口。
2. 在初始化逻辑里插入回调。
3. 定义 `InitializingBean` 和 `DisposableBean`。
4. 把 `init-method`、`destroy-method` 也接上，注意不要让 `InitializingBean` 无意中短路配置式初始化。
5. 容器关闭时统一清理。

这章写完，你的对象才算真正进入 Spring 世界。
