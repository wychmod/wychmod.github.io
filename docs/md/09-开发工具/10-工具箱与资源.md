## 三、CSS 便捷代码

单行文本省略（商品名称过长等场景）：

```css
.selector {
  width: 200px; /* 或 max-width: 100%; 需有明确宽度限制 */
  overflow: hidden;
  text-overflow: ellipsis;
  white-space: nowrap;
}
```

关键点：必须配合明确的宽度（`width` 或 `max-width`）才能生效，否则文本会继续撑开容器。

> 💡 补充：归档原文中 CSS 片段的 `width:` 缺少具体值，使用时请自行补充如 `width: 200px;` 或 `max-width: 100%;`。
