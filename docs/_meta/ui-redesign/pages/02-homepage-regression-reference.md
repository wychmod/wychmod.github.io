## 2. Design Specification

### 2.1 Purpose Statement

首页是个人技术知识库的入口和气质源头。它在首屏同时说明作者是谁、知识范围是什么、如何搜索、如何进入终端以及如何继续阅读。对后续页面而言，它不是要复制的版式，而是要继承的秩序。

### 2.2 Aesthetic Direction

唯一方向：**Editorial / magazine，研究者的数字书房封面 + 内页**。
深色区表达结构、系统、命令和知识关系；纸白区表达阅读、写作、批注和修订。其他页面只继承这套语义，不必都做首页式大 Hero。

### 2.3 Color Palette

以后所有派生页面必须保持这些主 token 不漂移：

| 语义 | 色值 | 首页位置 | 派生页面用法 |
|---|---|---|---|
| 暖石墨 | `#0D100E` | 顶部导航、系统封面 | 导航、工具工作台、终端 |
| 深墨 | `#131713` | 终端预览、深色层 | 代码/命令局部组件 |
| 灰纸白 | `#E9E5DC` | 首页纸白内页 | 文档和工具主体背景 |
| 浅纸白 | `#F2EEE5` | 输入、行面、局部纸面 | 表格、输入、轻型工作面 |
| 墨色正文 | `#20211D` | 标题与正文 | 主体文字 |
| 次级文字 | `#66685F` | 摘要、元信息 | 日期、路径、说明 |
| 信号绿 | `#24D18F` | “进入知识库”、在线状态 | 主动作、成功、焦点 |
| 旧金 | `#C8A96B` | 当前导航、图谱图标、卷号 | 编号、当前项、索引线 |

禁止在派生页面中重新引入紫色主视觉、蓝紫渐变、玻璃拟态、霓虹光球或纯黑黑客风。

### 2.4 Typography

- 首页主标题使用中文衬线，桌面约 `56–64px`，移动约 `34–38px`。
- 正文与控件使用中文无衬线，桌面约 `15–18px`。
- 系统路径、日期、状态、终端命令使用等宽字体，约 `12–13px`。
- 字距为 `0`，不使用负字距。
- 派生页面可缩小标题，但不能换成通用系统字体或营销字体。

### 2.5 Layout Strategy

首页是 12 栏非对称布局：

```text
桌面 1440 x 900
┌────────────────────────────────────────────┐
│ top nav 60px, warm graphite                │
├───────────────────┬────────────────────────┤
│ left 5 columns    │ right 7 columns         │
│ author/search/CTA │ knowledge graph/terminal│
├────────────────────────────────────────────┤
│ FIELD NOTES binding strip                  │
├──────────────┬─────────────┬───────────────┤
│ recent notes │ author note │ knowledge index│
└──────────────┴─────────────┴───────────────┘
```

移动端不是缩小桌面图谱，而是重排：

- 顶部 `56–60px`
- `16px` 安全边距
- 标题与头像居中，说明文字可居中或窄行
- 搜索满宽
- CTA 两列，极窄屏单列
- 五步研究方法横向压缩为图标/编号行或纵向
- 知识图谱变为两列文本索引
- 终端预览变为一行启动条
- FIELD NOTES 在首屏后自然出现

### 2.6 Files to Change

本任务本身允许修改的运行时文件：**无**。

允许读取但不得修改：

- `docs/_coverpage.md`
- `docs/README.md`
- `docs/index.html`
- `docs/assets/css/studio-tokens.css`
- `docs/assets/css/homepage-v2.css`
- `docs/assets/js/homepage-v2.js`

除非用户明确要求修首页，否则 `git diff` 中不应出现以上文件的改动。

### 2.7 Behaviors That Must Not Regress

首页冻结行为：

- `form#cover-search` 提交后桥接 Docsify Search。
- `/` 聚焦首页搜索时不得影响输入框内正常输入。
- `Ctrl/Cmd + K` 只打开现有 `#terminal-window`。
- `[data-open-terminal]` 与右下角终端按钮打开同一个终端。
- `Esc` 关闭终端并恢复焦点。
- `进入知识库` 和 `查看最新笔记` CTA 可用。
- 9 域知识图谱链接可点击且不 404。
- GitHub 头像固定尺寸、alt、失败回退可用。
- Lucide 图标在 Docsify `doneEach` 后幂等重绘。
- 首页不渲染 Gitalk、全局页脚和编辑此页的重复入口。
- `.is-home` 与 `.is-article` 路由状态准确切换。

## 3. 参考图视觉复盘

### 3.1 桌面端

画布左侧是当前首页桌面稿，右侧是手机稿。桌面宽屏中顶部导航高约 `60px`，背景为接近 `#0D100E` 的暖石墨。左侧品牌 `wychmod / workspace`，中间导航当前项“知识库”用旧金文字和短线强调，右侧依次是 GitHub 图标、`>_ Ctrl K` 终端按钮、信号绿“进入知识库”按钮。

首屏主体为左右分栏，整体并非纯深色，而是淡纸白/暖纸感背景。左栏约占 5 栏：路径眉题、两行大标题“在复杂系统里，留下清晰路径。”、作者说明、圆形真实头像、搜索框、两个 CTA、五步研究方法。右栏约占 7 栏：系统路径、最后更新时间、中心圆形知识图谱、8 个围绕节点、底部深墨终端状态条。

首屏下方是 FIELD NOTES 装订带。该区域从系统封面进入阅读内页，纸白更明显，分为卷号、最近更新列表、作者手记和知识索引。线条比文章页更轻，装订带是语义过渡，不使用渐变。

### 3.2 手机端

手机宽 `390px`，顶部导航高约 `56px`，左侧品牌，右侧 GitHub 和菜单。主体边距约 `16px`。标题居中，头像居中，搜索框满宽，两个 CTA 并排。五步研究方法压缩为小图标/编号序列，知识图谱变为两列领域索引，终端预览变成单行启动条。FIELD NOTES 列表纵向排列。

注意：移动端大标题在本图中居中，这只属于首页。文章页、全站地图和工具页不应盲目居中，应根据页面任务决定；当前用户特别强调过桌面大标题应居左，移动端可居中。

## 4. 首页 DNA 提取给其他页面

后续页面可以复用这些东西：

- `60px` 左右的暖石墨全局导航。
- `1440px` 最大宽度和桌面 `40px` gutter。
- 手机 `16px` gutter。
- 系统路径横条：`WYCHMOD / 页面领域 / 页面标题`。
- 旧金作为当前项、编号、章节线。
- 信号绿作为主动作、在线、成功、焦点。
- 衬线标题 + 无衬线正文 + 等宽路径。
- `1px` 发丝线和 `3px/6px` 圆角。
- 深色只表达系统/命令/工作台，纸白表达阅读/解释。
- 人文感来自真实来源、修订、作者判断，而非装饰物。

后续页面不应复制这些东西：

- 首页的大型 Hero 高度。
- 首页中心知识图谱。
- 首页作者头像布局。
- 首页 FIELD NOTES 具体文章和日期。
- 图中任何虚构统计、更新时间、终端输出或研究记录。
- 首页移动端标题居中规则，除非页面本身也是个人/封面类页面。

## 5. 回归对比方法

每完成一个非首页页面任务，至少执行以下首页保护检查：

1. 打开 `#/`，截图 `1440×900` 和 `390×844`。
2. 对比顶部导航：
   - 品牌位置无变化
   - “知识库”选中线无变化
   - GitHub、终端、进入知识库位置无变化
3. 对比首屏：
   - 桌面左栏仍居左排版
   - 手机标题和头像仍居中
   - 搜索框、CTA、五步研究方法不重叠
   - 图谱文字和终端状态可读
4. 对比纸白区：
   - FIELD NOTES 装订带未被非首页样式污染
   - 最近更新、作者手记、知识索引布局无偏移
5. 验证交互：
   - 首页搜索
   - 两个 CTA
   - 9 域链接
   - 终端预览
   - `Ctrl/Cmd + K`
   - `Esc`
   - 首页 → 文章 → 首页
6. 打开控制台，确认无新增 error。

如果出现首页回归，只允许修改新页面引入的 CSS/JS 作用域。不要改首页文件来迎合新页面。

## 11. 当前首页运行基线锁定

Image 02 的特殊性在于：它不是开发任务，而是所有后续页面的“保护线”。实现模型必须知道哪些文件属于首页运行基线，任何非首页页面的 UI 改造都不应让这些文件产生 diff。

冻结文件：

| 文件 | 作用 | 回归风险 |
|---|---|---|
| `docs/_coverpage.md` | 深色首页封面，包含作者、搜索、CTA、9 域图谱、终端预览 | 改动会直接重做首页首屏 |
| `docs/README.md` | 纸白 FIELD NOTES、最近更新、作者手记、知识索引 | 改动会改变首页下半部 |
| `docs/index.html` | Docsify 配置、全局导航、终端、Gitalk 例外、搜索桥接 | 改动可能破坏路由、终端、搜索和文章页 |
| `docs/assets/css/studio-tokens.css` | 首页视觉 token | 改动会让全站色彩漂移 |
| `docs/assets/css/homepage-v2.css` | 首页专用样式 | 改动会造成首页截图变化 |
| `docs/assets/js/homepage-v2.js` | 首页交互、路由状态、Lucide 重绘 | 改动会造成首页搜索/终端/路由状态回归 |

允许读取这些文件以继承风格，但不允许在非首页页面任务中修改它们。若实现模型发现必须改 token 才能让其他页面一致，应停止并单独提出“全站 token 变更”任务，不要夹带在页面改造中。

## 12. 首页像素级回归判定表

每做完一个页面，至少用以下表格检查首页。不是要求像素 100% 截图 diff，而是要求关键结构和行为无漂移。

| 区域 | 桌面 `1440×900` 预期 | 移动 `390×844` 预期 |
|---|---|---|
| 顶部导航 | 高约 60px；品牌在左；知识库旧金选中；GitHub、终端、进入知识库位置稳定 | 高约 56px；品牌在左；GitHub 与菜单在右；不换行 |
| Hero 标题 | 左栏大标题居左；两行以内；不被搜索/头像挤压 | 标题居中；头像居中；段落窄行可读 |
| 搜索 | 输入框宽度、边框、placeholder 稳定；不显示 Ctrl/Cmd K | 满宽；不会与 CTA 重叠；`/` 聚焦不影响输入 |
| CTA | 主按钮信号绿；次按钮描边；hover 不改变布局 | 两列或极窄单列；点击区域不小于 44px |
| 研究方法 | 五步横向稳定，数字和图标不乱位 | 压缩为可读序列或纵向；文字不小于 12px |
| 知识图谱 | 右栏图谱完整可读；连接线不丢失；终端预览在下方 | 图谱降级为领域索引；不是缩小桌面图谱 |
| FIELD NOTES | 装订带露出；最近更新、作者手记、知识索引布局稳定 | 列表纵向排列；无横向滚动 |
| 终端 | `>_ Ctrl K` 和预览均打开现有终端 | 右下角终端按钮不遮挡 CTA 或正文 |

如果任何一项变化来自新页面 CSS/JS，就说明新页面作用域过宽。

## 14. 作用域隔离红线

其他页面常见错误是写出这些选择器：

```css
body { ... }
nav a { ... }
.markdown-section { ... }
.sidebar { ... }
.search input { ... }
.button, .card, section { ... }
```

这些选择器可能影响首页。应改成：

```css
body.is-article .markdown-section { ... }
body.is-article .sidebar { ... }
.tool-page .tool-button { ... }
.resume-page .resume-section { ... }
.personal-notes-page .personal-cover { ... }
```

首页专用 class 如 `.home-v2`、`.home-hero`、`.home-graph`、`.home-field-notes` 只能由首页文件使用。非首页页面不得复用这些 class 做“偷懒继承”，否则会被首页 CSS 误命中。
