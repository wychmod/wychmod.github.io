# 全站 UI 图片生成提示词（最终精简版）

> 适用项目：wychmod Developer Workspace  
> 文档版本：V2.0，按当前首页视觉实现增强  
> 设计基线：Editorial / magazine，研究者的数字书房  
> 使用方式：每个代码块都是完整、独立、可直接复制的提示词。  
> 输出方式：每条提示词同时生成 `1440 x 900` 桌面端与 `390 x 844` 手机端两张独立画板；若工具一次只能生成一张，分别保留对应尺寸运行两次。

## 设计规格

- Purpose：建立统一的个人技术知识库、工程工具和作者表达空间。
- Aesthetic：Editorial / magazine，研究者的数字书房。
- Palette：暖石墨 `#0D100E`、深墨 `#131713`、灰纸白 `#E9E5DC`、浅纸白 `#F2EEE5`、信号绿 `#24D18F`、旧金 `#C8A96B`。
- Typography：Source Han Serif SC / Noto Serif SC；Source Han Sans SC / Noto Sans SC；IBM Plex Mono / JetBrains Mono。
- Geometry：12 栏非对称网格、最大圆角 6px、细分隔线、无卡片套卡片。
- Icons：统一使用 Lucide，禁止 Emoji 图标。
- Human tone：通过真实作者、学习轨迹、批注、来源、修订和实践反思体现人文感，不通过咖啡、羽毛笔、旧书或做旧污渍装饰。

### 当前首页视觉 DNA

- 顶部导航约 `60px`，首页为深色，内页可使用纸白，但品牌、间距、旧金选中线和终端入口保持一致。
- 内容最大宽度 `1440px`，桌面安全边距 `40px`；手机安全边距 `16px`。
- 深色区表达系统、结构、路径、命令和工具；纸白区表达阅读、写作、解释、批注和修订。
- 每个派生页面都应保留一条“系统路径横条”：左侧为 `WYCHMOD / 页面领域 / 页面标题`，右侧为真实 `UPDATED` 或状态。
- 线条统一为 `1px`，深色区使用低对比浅线，纸白区使用低对比墨线；圆角只有 `3px` 和 `6px`。
- 旧金用于图标、编号、当前导航和编辑标记；信号绿只用于主动作、成功状态、焦点和阅读进度。
- 纸白区允许极轻噪点，但不能泛黄、做旧或出现污渍；整页最多一个 `W` 印章或一组页码。
- 人文内容只能来自真实头像、真实文章、真实修改记录、真实来源和作者确认；没有来源的模块直接隐藏。

## 五、生成与验收要求

每次生成后检查：

1. 是否同时提供桌面和手机两张独立画板。
2. 是否保持同一导航、侧栏、字体、颜色、线条和圆角系统。
3. 是否避免紫色、蓝紫渐变、玻璃拟态、Emoji 图标和卡片墙。
4. 是否只使用项目真实标题、栏目、功能和数据。
5. 是否兼顾搜索、终端、侧栏、代码、表格、图表、评论、打印与空状态。
6. 是否通过内容、修订、来源和作者判断体现人文感，而不是用装饰物模拟人文感。
7. 是否像真实可实现的网页正视图，而不是设备模型、透视展板或概念海报。
